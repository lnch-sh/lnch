lnch

Launch any dev stack in one command.

$ lnch
web   healthy   https://localhost:5173
api   healthy   https://localhost:8080
share https://a7k2m9qx.lnch.sh/

Install

git clone https://github.com/lnch-sh/lnch
cd lnch
go install ./cmd/lnch

Go 1.23 or newer, from a checkout of the repo. install.sh is the release installer, once a release exists.

Read the docs / detect, launch, share, local HTTPS, and the agent tools.
